Abstract

Academic publishers do not agree on what a finished manuscript should look like. Bloomsbury’s academic division prescribes nearly everything, from the shape of a quotation mark to the order of the preliminary pages. Routledge, part of Taylor & Francis, has no house style at all; it asks for consistency, an abstract for every chapter and a carefully named set of files. Students and early-career researchers who write for both usually learn these rules the slow way, through returned files and long lists of copy-editing queries.

PressReady is a modular skill that teaches a large language model to apply both sets of guidelines. I read the three official documents in full, 99 pages in all, and turned them into 632 separate rule statements. These are arranged in eleven Markdown files: a short routing file that tells the model how to work, seven rule modules, a point-by-point comparison of the two publishers, a set of checklists and a file of worked examples. The skill can be uploaded to Claude as it is, or added as knowledge files to other assistants.

A demonstration on a sample chapter shows one draft formatted for each publisher. The analysis finds that the two houses agree on only five of thirty comparable points, and that their differences follow a clear pattern: Bloomsbury governs the sentence, while Routledge governs the file.

Why this project

Anyone who has prepared a chapter for an edited volume knows the moment. The argument is finished, the deadline is close, and then the publisher’s guidelines arrive: thirty or sixty pages on dashes, dates, file names and image resolution. Most of it is sensible. Very little of it is taught in a classroom. Many students in India write with American spellings picked up from software, British punctuation picked up at school, and citation habits borrowed from whichever article they read last. The result is a manuscript that is correct in places and consistent nowhere.

Large language models are good at this kind of patient, rule-bound checking, but only when they are given the rules. Ask a general assistant to ‘format this for Routledge’ and it will guess, and its guesses tend to drift towards whatever style it has seen most often. PressReady gives the model the publishers’ actual rules, in a form it can load when it needs them, together with clear instructions about what it must never do, such as inventing a page number or quietly rewording a quotation.

Objectives

  1. To read the Bloomsbury and Routledge (Taylor & Francis) author guidelines closely and extract every rule that affects how a manuscript is prepared and submitted.
  2. To organise those rules into a modular skill that a language model can load in parts, so that it reads only what a given task needs.
  3. To write working instructions that keep the model to formatting and stop it from inventing references, data or quotations.
  4. To compare the two publishers point by point and show where an author moving between them is most likely to go wrong.
  5. To demonstrate the skill on a sample chapter and release the whole package openly for students to use.

Method

The work moved in five stages, from the printed page to a package a model can use.

  1. Close reading

    I read all three documents page by page: Bloomsbury’s House Style Guidelines for Authors and Editors (version 2, September 2025, 66 pages, including appendices for T&T Clark, the Arden Shakespeare and Methuen Drama), and the Taylor & Francis Manuscript preparation guide (30 pages) and Manuscript submission guide (3 pages). The text was also extracted digitally, so that nothing in the skill rests on memory.

  2. Extraction

    Each instruction was rewritten as a short rule a model can act on, and the guide’s own example was kept wherever there was one. Purely descriptive material, such as why endorsements help a book sell, was reduced to a line.

  3. Encoding

    The rules were grouped by publisher and by task into seven rule modules. Three further files sit on top of them: a comparison, a set of checklists and worked examples. A routing file, SKILL.md, holds the workflow, the ground rules and a quick reference, and tells the model which module to open.

  4. Counting and comparison

    Every rule statement in the rule modules (a bullet point, a numbered step or a row of a rule table) was counted and assigned to one of eight categories. I then chose thirty topics that either guide could reasonably be expected to cover and marked each as the same, different, or covered by one publisher only.

  5. Demonstration

    A short fictional chapter opening, written with the errors students commonly make, was formatted with the skill for both publishers. The results shown on this page were checked by hand against the guides.

The skill

PressReady is written in plain Markdown, which almost every assistant can read. It follows the pattern of Claude’s skills: a short SKILL.md file whose name and description tell the model when to use it, and a set of modules the model opens only when a task calls for them. That keeps the model’s attention on the manuscript rather than on rules it does not need.

  1. BriefFind out the publisher, the type of book, UK or US English, the referencing system and any editor’s instructions.
  2. LoadOpen only the modules the task needs, using the module map in SKILL.md.
  3. AuditList every problem in a table, sorted into blocking issues, style issues and queries for the author.
  4. ApplyReturn the corrected text in full, changing form but not content, with [CHECK] placeholders for anything missing.
  5. FinishTick the publisher’s checklist and list the files and forms the author still has to prepare.

What the skill will not do

  • Invent an author, a title, a year, a page number, a DOI, a URL or an ORCID iD. Missing details become visible placeholders.
  • Change the wording, spelling or punctuation inside a quotation, apart from the outer quotation marks that house style controls.
  • Rewrite the author’s argument. It formats; it does not compose.
  • Decide whether something needs copyright permission. It explains the publisher’s process and leaves the judgement to the author and editor.
  • Override the editor. Instructions from a commissioning editor always win over the general guide.

      Analysis

      Five findings came out of the close reading and the counts. The second research question is taken first, because its answer shapes the design that answers the first.

      405Bloomsbury rule statements, against 227 for Routledge

      Two guides, two kinds of rule

      The Bloomsbury guide produced 405 rule statements and the two Taylor & Francis documents produced 227. The gap does not mean that Routledge cares less about manuscripts. It cares about different things. Almost two thirds of Bloomsbury’s rules (257 of 405) concern language and referencing: how to write a date, when to spell out a number, where the full point goes in a quotation, how to order three books by the same author. The two Taylor & Francis documents give these questions eighteen rules between them and, in effect, one answer, which is to be consistent.

      Its attention goes instead to the parts of a book that a production team has to handle as objects. Figures, front matter, permissions and file submission account for 185 of its 227 rules, more than four in five.

      Bloomsbury governs the sentence. Routledge governs the file.

      5of thirty points on which the guides agree

      Agreement is rare

      Of the thirty points compared, the guides agree on five. Neither lets an author call a figure ‘above’ or ‘below’, neither allows images to be pasted into the text, both ask for bias-free language, both want advance warning of sensitive quoted material, and both ask for Unicode fonts with a PDF for unusual characters. They differ on seventeen points, and on the remaining eight only one publisher has a rule at all.

      Some differences are direct opposites. Bloomsbury wants the first line of each paragraph indented and no extra space between paragraphs; Routledge wants a blank line and no indent. Bloomsbury numbers pages continuously through the whole manuscript; Routledge starts again at 1 in every chapter file. Bloomsbury allows an epigraph once permission is cleared; Taylor & Francis does not allow epigraphs at all. Even the brackets around a figure callout differ. These are small things, but a chapter moved from one publisher to the other without changes would be wrong in all of them at once.

      2reference patterns in Bloomsbury’s own examples

      The guides are not perfectly consistent themselves

      Close reading turned up small inconsistencies inside the sources. Bloomsbury’s reference-list examples use two patterns, one with the year in parentheses after the name and one in the Chicago manner with the year after a full point. One bibliography example leaves out its year, one in-text example closes with an extra parenthesis, and the list of appendices names Appendix C twice where the second should be D. The Taylor & Francis guide has its own slips (‘aware aware’, ‘forma,t’).

      A human copy editor would not be troubled by any of this. A language model is, because it learns from examples very literally. Pasted in unchanged, the examples would teach the model the slips as well as the rules. PressReady therefore states the majority pattern as the rule and flags the exceptions where they occur.

      [CHECK]the placeholder that stops invention

      The most important rules are about what not to do

      Both guides depend on information only the author holds: the date of an interview, the page range of a chapter, a DOI, an ORCID iD, the exact wording a rights holder wants in a credit line. These are exactly the details a language model is tempted to fill in, because a plausible guess looks tidier than a gap. While working through the demonstration chapter, the most useful single device turned out to be the [CHECK] placeholder. It lets the formatting go ahead without inventing anything, and it hands the author a short list of things to look up.

      1publisher with a written AI policy in these guides

      AI policy sits inside the task

      Taylor & Francis states that a language model cannot be an author and that any AI help with generating content must be acknowledged in the book. A formatting skill sits right on that boundary. Changing ‘40%’ to ‘40 per cent’ is not authorship; drafting an abstract comes much closer to it. The skill draws the line in so many words. It formats and checks freely, but whenever it drafts text (an abstract, a biography, alt text) it tells the user to review the draft and acknowledge the help. The Bloomsbury guide used here does not mention AI, so the skill sends the author to Bloomsbury’s own policy and to their editor.

      Answer to research question 2

      The two publishers agree on very little of substance. They share a concern for inclusive language, clean files and specific references to figures, but they divide the work of style in opposite ways. Bloomsbury fixes the answers to questions of language and referencing in advance. Taylor & Francis leaves those answers to the author, demands consistency, and concentrates its rules on structure, images, permissions and delivery. For an author writing for both, the practical meaning is that there is no neutral ‘academic format’. A manuscript has to be prepared for one house at a time, and moving it to the other means checking at least the seventeen points where they differ.

      Answer to research question 1

      The design that works has four parts. First, a router: SKILL.md tells the model what to ask, which module to open and in what order to work. Second, modules small enough to load only when needed, split by publisher and by task, so a Routledge job never carries Bloomsbury’s rules on pre-decimal currency. Third, ground rules that limit the model to formatting, forbid invention and require it to name the rule behind each change. Fourth, checklists and worked examples that show the model what a good answer looks like.

      Plain Markdown makes the package portable. The same files work as a Claude skill, as knowledge files for a custom GPT or Gem, or as one long prompt for any other assistant. ‘Reliably’ remains the hard word in the question, and the limitations below explain why the author still has to check the result.

      Discussion

      For students, the value of PressReady lies less in the corrected text than in the reasons attached to each correction. Every change points to a module and a section, so the author can see that ‘40 per cent’ comes from Bloomsbury’s rule on numbers and not from the model’s taste. After a few chapters, that is how house style actually gets learnt.

      The project also says something about how rules travel into language models. Publishers write guidelines for people, and people fill gaps with common sense or ask an editor when unsure. A model has neither habit unless someone writes it down. A good share of the work on PressReady went into instructions a human reader would never need: ask about the editor’s wishes, leave quotations alone, say when a guide is silent instead of making up a rule.

      There is a real risk of over-trust. A neatly formatted chapter looks finished, and the skill can still make mistakes, particularly in long texts where small rules are easy to drop. The checklists exist partly for this reason. They put the final look back in the author’s hands.

      Some rules matter especially for writers in India. Bloomsbury’s own example of a localised term is ‘five lakh (500,000) rupees’, and its advice to explain such units is easy to overlook. Spelling is another trap. Bloomsbury’s British English uses -ize (organize, recognize), which many Indian students have been taught to treat as American. The skill handles this explicitly instead of leaving it to the model’s habits, and it keeps ‘analyse’ with an s, as the style sheet asks.

      Finally, the comparison is a small piece of book history. Bloomsbury’s guide reads like the heir of the printing house rule book, careful about dashes and dates. The Taylor & Francis guide reads like a production manual for a publisher handling thousands of titles a year in print and digital form, careful about files, rights and metadata. Neither approach is wrong. They simply put the author’s effort in different places.

      Limitations

      The skill is useful, but it has clear edges. These are the ones that matter most.

      • Books, not journals

        All three sources are guidelines for books. Most student research goes to journals, and Taylor & Francis and Bloomsbury journals have their own instructions for authors. The skill tells the model to say so and ask for the journal’s guide, but it cannot replace it.

      • A snapshot in time

        The Bloomsbury guide is version 2 of September 2025. The Taylor & Francis copies carry no date. Publishers revise their guidance, and an older skill will quietly fall out of step.

      • Missing companion documents

        The Taylor & Francis guides refer to forms and guides that were not part of the source set: the submission checklist, the notes for the copyeditor form, the permissions log and declaration, and the guides to LaTeX, indexing, alt text and discoverability.

      • What a model cannot see

        Pasted text loses Word styles, highlighting and page layout, and a model cannot measure an image’s resolution unless it is told the pixel size. Some checks can only ever be reminders.

      • No guarantee of compliance

        Language models can drift, skip rules in long documents, or apply a rule where it does not belong. The ground rules reduce invention but cannot rule it out. Every output needs a human check.

      • A demonstrative evaluation

        The skill was tested on one sample chapter and checked by hand. There was no user study and no scored comparison across different assistants, so claims about reliability are modest.

      • A rough measure

        Rule statements were counted as written. A line of an abbreviation table weighs the same as a rule on line spacing, so the counts show where each guide spends its attention, not how important each rule is.

      • Specialist lists summarised

        Bloomsbury’s appendix of Dead Sea Scrolls sigla, works of Philo and some five hundred journal abbreviations is described, not copied. The skill tells the model never to guess these and to send the author to the source.

      • The editor still decides

        Both publishers let commissioning editors set their own requirements. The skill can only follow those instructions if the author passes them on.

      Conclusion and next steps

      PressReady takes three documents written for human authors and rewrites them as instructions a language model can follow, with the limits a model needs. The comparison shows how differently two respected publishers think about the same job, and why formatting a chapter once for a general ‘academic style’ is never quite enough.

      Three directions would make the work stronger. The first is a module for journal articles, starting with the Taylor & Francis journal instructions that many students meet first. The second is a proper test: a set of sample chapters with known errors, run through several assistants and scored. The third is breadth, adding the university presses most used by researchers in India, so that the same approach can serve a wider range of authors.
